Como ficaria a etapa 3 e a etapa 4

Hoje a seleção de planos é uma só para o estudo inteiro — escolher para um grupo sobrescreve o outro. Passa a ser uma seleção por grupo de beneficiários, e a etapa 4 oferece a cada plano vigente só o que foi escolhido para ele.

É aqui que a correção aparece. O dropdown dos funcionários lista três planos; o da diretoria, dois. Hoje os dois listam os cinco, e é isso que faz o Executivo R2 aparecer como opção para as 36 vidas do S750 — a Ferrari para todo mundo.

O componente não muda. O dropdown continua igual, com o valor ao lado de cada plano. O que muda é a lista que ele recebe: hoje vem da seleção do estudo, passa a vir da seleção daquele grupo.
